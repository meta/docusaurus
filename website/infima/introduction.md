# Introduction

Infima is the styling layer of `@docusaurus/theme-classic`: a CSS framework for content-driven websites, with styles for common UI components (grid, buttons, navbar, menu…) and dark mode support.

Infima is themed with CSS variables. Sites customize it by overriding the `--ifm-*` CSS variables, and third-party components can read them to match the site style.

The Infima source code comes from the [upstream Infima repository](https://github.com/facebookincubator/infima/tree/87bc1dbfde5dfb2a70b5ff105b5f2f5ee130c2ab).

## Why the name "Infima"?

In mathematics, the infimum (abbreviated inf; plural infima) of a subset S of a partially ordered set T is the greatest element in T that is less than or equal to all elements of S, if such an element exists.

Infima provides websites with the minimal CSS needed to build a modern and responsive website. If T is the set of things needed to build a website, and S the components needed, the infimum of a website is its styling.
