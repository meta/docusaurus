# Menu

## Basic

```html
<nav class="menu">
  <ul class="menu__list">
    <li class="menu__list-item">
      <a class="menu__link" href="#url">First Level Item</a>
    </li>
    <li class="menu__list-item">
      <a class="menu__link menu__link--active" href="#url">Active Item</a>
    </li>
    <li class="menu__list-item">
      <a class="menu__link" href="#url">Third Level Item</a>
    </li>
  </ul>
</nav>
```

## With Sublist

```html
<nav class="menu">
  <ul class="menu__list">
    <li class="menu__list-item">
      <a class="menu__link menu__link--sublist" href="#url">Category</a>
      <ul class="menu__list">
        <li class="menu__list-item">
          <a class="menu__link" href="#url">Nested Item</a>
        </li>
        <li class="menu__list-item">
          <a class="menu__link" href="#url">Another Item</a>
        </li>
      </ul>
    </li>
  </ul>
</nav>
```

## With Caret

```html
<nav class="menu">
  <ul class="menu__list">
    <li class="menu__list-item">
      <div class="menu__list-item-collapsible">
        <a class="menu__link menu__link--sublist-caret" href="#url">
          With Caret
        </a>
      </div>
      <ul class="menu__list">
        <li class="menu__list-item">
          <a class="menu__link" href="#url">First Item</a>
        </li>
        <li class="menu__list-item">
          <a class="menu__link" href="#url">Second Item</a>
        </li>
      </ul>
    </li>
  </ul>
</nav>
```

## With Custom Caret Button

```html
<nav class="menu">
  <ul class="menu__list">
    <li class="menu__list-item">
      <div class="menu__list-item-collapsible">
        <a class="menu__link" href="#url">Category</a>
        <button
          type="button"
          class="clean-btn menu__caret"
          aria-label="Toggle the Category category"></button>
      </div>
      <ul class="menu__list">
        <li class="menu__list-item">
          <a class="menu__link" href="#url">First Item</a>
        </li>
        <li class="menu__list-item">
          <a class="menu__link" href="#url">Second Item</a>
        </li>
      </ul>
    </li>
  </ul>
</nav>
```

## Nested Levels

```html
<nav class="menu">
  <ul class="menu__list">
    <li class="menu__list-item">
      <div class="menu__list-item-collapsible">
        <a class="menu__link menu__link--active" href="#url">First Level</a>
        <button
          type="button"
          class="clean-btn menu__caret"
          aria-label="Toggle the First Level category"></button>
      </div>
      <ul class="menu__list">
        <li class="menu__list-item">
          <div class="menu__list-item-collapsible">
            <a class="menu__link" href="#url">Second Level</a>
            <button
              type="button"
              class="clean-btn menu__caret"
              aria-label="Toggle the Second Level category"></button>
          </div>
          <ul class="menu__list">
            <li class="menu__list-item">
              <a class="menu__link" href="#url">Third Level Item</a>
            </li>
            <li class="menu__list-item">
              <a class="menu__link" href="#url">Another Item</a>
            </li>
          </ul>
        </li>
      </ul>
    </li>
  </ul>
</nav>
```

## Collapsed State

Add the `menu__list-item--collapsed` class to collapse a menu section:

```html
<nav class="menu">
  <ul class="menu__list">
    <li class="menu__list-item menu__list-item--collapsed">
      <div class="menu__list-item-collapsible">
        <a class="menu__link" href="#url">Collapsed Section</a>
        <button
          type="button"
          class="clean-btn menu__caret"
          aria-label="Toggle the Collapsed Section category"></button>
      </div>
      <ul class="menu__list">
        <li class="menu__list-item">
          <a class="menu__link" href="#url">Hidden Item</a>
        </li>
      </ul>
    </li>
  </ul>
</nav>
```
