# Many inline SVGs

Inline SVGs imported as React components share the same HTML document. Their ids (gradients, masks, clip paths...) must not clash with each other. See [#8297](https://github.com/facebook/docusaurus/issues/8297).

Each inline SVG below must look like the `<img>` reference rendering of the same file.

## Gradients {/* #gradients */}

Two SVG files with the same name (`gradient.svg`) in different folders, each using its own `<linearGradient>` with a different id.

Inline SVG components:

<GradientA />
<GradientB />

Images (reference rendering):

<img
  src={new URL('./_fixtures/a/gradient.svg', import.meta.url).href}
  alt="a/gradient.svg"
/>
<img
  src={new URL('./_fixtures/b/gradient.svg', import.meta.url).href}
  alt="b/gradient.svg"
/>
