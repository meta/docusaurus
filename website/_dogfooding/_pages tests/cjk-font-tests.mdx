# CJK font tests

Chinese, Japanese and Korean text rendered with the theme's font stack, each paragraph marked with its `lang` attribute. See [#11727](https://github.com/meta/docusaurus/issues/11727).

The characters 今令直骨角次 exist in every one of these languages, but each region draws some of them with a different shape. With the right font, they should look different in each paragraph below.

## Without a specific `lang`

This paragraph inherits the page's `lang="en"`, so the browser picks the fallback font of the Han characters on its own: 今令直骨角次 — 文档网站 ドキュメント 문서.
