# CJK font tests

Chinese, Japanese and Korean text rendered with the theme's font stack, inside an element marked with its `lang` attribute. See [#11727](https://github.com/meta/docusaurus/issues/11727).

The same 6 Han characters exist in every one of these languages, but each region draws some of them with a different shape. With the right font, they should look different on each page:

- [Simplified Chinese](/tests/pages/cjk-font-tests/zh-cn)
- [Traditional Chinese](/tests/pages/cjk-font-tests/zh-tw)
- [Japanese](/tests/pages/cjk-font-tests/ja)
- [Korean](/tests/pages/cjk-font-tests/ko)
- [Without a specific `lang`](/tests/pages/cjk-font-tests/no-lang)

Each language has its own page because Chromium on Linux reuses the first fallback font it picked for a character in the whole tab, whatever the `lang`. Reload the page after navigating to another language.
